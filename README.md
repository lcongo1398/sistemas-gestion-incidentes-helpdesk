# 📋 Sistema de Gestión de Incidentes - Help Desk

Sistema web completo para registrar, consultar, actualizar y eliminar tickets de incidencias, con API REST y base de datos PostgreSQL.

---
## 🛠️ Tecnologías utilizadas
- **Backend:** Node.js + Express
- **Base de datos:** PostgreSQL
- **Frontend:** HTML5 + CSS3 + JavaScript
- **Herramientas:** Visual Studio Code, Git, GitHub
- **Pruebas API:** Postman / Navegador
