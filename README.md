# Sistema de Gestión de Incidentes - Help Desk
**Actividad 8 y 9 - Desarrollo de Sistemas Informáticos**
Universidad Técnica de Manabí

## 🛠️ Tecnologías utilizadas
- **Backend**: Node.js + Express
- **Base de Datos**: PostgreSQL
- **Frontend**: React.js
- **API**: RESTful con operaciones CRUD completas

## 📋 Funcionalidades
✅ Crear nuevos tickets de incidentes
✅ Listar todos los incidentes registrados
✅ Editar detalles y estado de los tickets
✅ Eliminar registros
✅ Validación de campos y protección XSS
✅ Valores permitidos:
  - Categoría: Red / Hardware / Software
  - Prioridad: Alta / Media / Baja
  - Estado: Abierto / En proceso / Cerrado
